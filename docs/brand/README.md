# RigWorks logo exports

The symbol ("interlock") and the Archivo wordmark are **provisional** per DESIGN.md v2.0. Check the symbol for resemblance to existing marks before treating it as final.

## Files

- `svg/`: master vector files. Text is converted to outlines, so no font install is needed. Use these wherever possible.
  - `rigworks-lockup-*`: symbol + wordmark (the primary logo)
  - `rigworks-lockup-tagline-*`: lockup with "Build a rig that works."
  - `rigworks-wordmark-*`, `rigworks-symbol-*`: the parts on their own
  - `rigworks-app-icon.svg`: symbol on a graphite rounded square
- `png/`: transparent PNGs at 1024 and 2048 px wide (symbols at 512 and 1024 px)
- `favicon/`: `favicon.svg` (switches colours with the browser's light/dark mode), `favicon.ico` (16/32/48/256), `apple-touch-icon.png` (180 px)

## Which variant

| Variant | Use on | Colours |
|---|---|---|
| `dark-bg` | Dark backgrounds (default) | #f4f4f5 + lime #a3e635 |
| `light-bg` | Light backgrounds | #0b0d12 + #3f6212 (7.08:1 on white) |
| `mono-white` | Dark backgrounds, one colour only | #f4f4f5 |
| `mono-black` | Light backgrounds, one colour only | #0b0d12 |

## Rules (from DESIGN.md)

- Clear space: half the symbol height on every side. The files are trimmed tight, so add the space when placing them.
- Minimum size: wordmark 14 px font size (about 75 px wide for the lockup); symbol alone 16 px.
- Never recolour "Rig", swap the colours, add glow/shadows/gradients, stretch, or retype the wordmark.

Wordmark: Archivo 700, width 112%, tracking -0.02em. Tagline: Archivo 500, width 100%. Archivo is SIL OFL 1.1.
